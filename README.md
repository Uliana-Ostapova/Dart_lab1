## Ответы на вопросы:

#### 1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
В Dart тип переменной указывается явно и проверяется до запуска программы. В Python типизация динамическая: тип переменной определяется во время выполнения.
Практическое преимущество Dart - часть ошибок можно обнаружить ещё до запуска программы.
#### 2.	Что означает `String?`? Чем отличается от `String`?
`String` означает, что переменная содержит строку и не может иметь значение `null`. `String?` означает. что переменная может содержать строку или значение `null`.
#### 3.	Зачем в Dart `final`, если в Python можно просто договориться не менять переменную?
`final` присваивает значение один раз и даёт возможность избежать случайного изменения такой переменной, что позволяет избежать ошибок.
#### 4.	Чем именованный параметр `{required String name}` отличается от позиционного? Приведите пример вызова.
Именованный параметр передаётся при вызове по имени (с явным указанием названия параметра), что делает вызов функции более понятным:
```csharp
void hello({required String name}) {
   print('Hello, $name!');
}
hello(name: 'Uliana');
```
Позиционный параметр передаётся по своему положению:
```csharp
void hello(String name) {
   print('Hello, $name!');
}
hello('Uliana');
```
